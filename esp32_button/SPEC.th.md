# สเปคอุปกรณ์ — ปุ่มกดที่คอร์ทจริง (ESP32)

สเปคละเอียดสำหรับซื้อของ ใช้คู่กับ [WIRING.th.md](WIRING.th.md) (แผนภาพ
ต่อสาย + งบประมาณรวม)

---

## 1. บอร์ด ESP32

| หัวข้อ | สเปค |
|---|---|
| ชิป | ESP32-WROOM-32 (dual-core Xtensa LX6 @240MHz) |
| รูปแบบบอร์ด | ESP32 DevKit V1 (บางร้านเรียก "ESP32 DevKitC" หรือ "NodeMCU-32S") |
| จำนวนขา | 30 หรือ 38 pin ก็ได้ทั้งคู่ (ไม่กระทบการทำงาน ต่างกันแค่ความกว้างบอร์ด) |
| ชิปแปลง USB↔Serial | CP2102 **หรือ** CH340 — ใช้ได้ทั้งคู่ (CP2102 มักไม่ต้องลง driver เพิ่มบน Mac/Windows รุ่นใหม่ ส่วน CH340 บางเครื่องต้องลง driver เอง) |
| หน่วยความจำ Flash | 4MB ขึ้นไป (มาตรฐานแทบทุกรุ่นที่ขายทั่วไปอยู่แล้ว) |
| ไฟเข้า | 5V ผ่านพอร์ต Micro-USB (บอร์ดแปลงเป็น 3.3V ให้เองในตัว ไม่ต้องทำอะไรเพิ่ม) |
| WiFi | 802.11 b/g/n **2.4GHz เท่านั้น** — เช็คก่อนว่า WiFi ที่จะใช้ที่คอร์ทปล่อยคลื่น 2.4GHz (ESP32 ต่อ WiFi 5GHz ไม่ได้) |
| กระแสไฟที่ใช้ | ปกติ 80-260mA, พีคได้ถึง ~500mA ตอนส่งสัญญาณ WiFi |
| คำค้นหาซื้อ | `ESP32 DevKit V1 CP2102` หรือ `ESP32-WROOM-32 38pin` |
| ราคาโดยประมาณ | 120-200 บาท |

**ไม่ต้องซื้อรุ่น** ESP32-S2 / S3 / C3 หรือ ESP8266 — คู่มือและโค้ดที่จะ
เขียนให้ต่อจากนี้อ้างอิงพินและไลบรารีของ ESP32-WROOM-32 (รุ่นคลาสสิก)
โดยเฉพาะ รุ่นอื่นพินไม่ตรงกัน

## 2. ปุ่มกด (Push Button)

| หัวข้อ | สเปค |
|---|---|
| ประเภทหน้าสัมผัส | **Momentary, Normally Open (NO)** — สำคัญมาก ต้องเป็น NO เท่านั้น (ไม่ใช่ NC/Normally Closed) เพราะวงจรออกแบบให้ปกติเปิดอยู่ กดแล้วค่อยครบวงจร ถ้าซื้อผิดเป็น NC ปุ่มจะทำงานสลับด้าน (ไม่กดกลับ trigger ตลอด) |
| ขนาดรูติดตั้ง (panel mount) | 12mm หรือ 16mm — 2 ขนาดนี้หาซื้อง่ายที่สุดในตลาด |
| เกรดกันน้ำ | **IP65 ขึ้นไป** ถ้าอยู่ใต้หลังคา/กันสาดคอร์ท, **IP67** ถ้าโล่งแจ้งเต็มตัวไม่มีอะไรบัง |
| พิกัดไฟฟ้าของหน้าสัมผัส | ไม่ต้องซีเรียสมาก วงจรนี้เป็นแค่สัญญาณลอจิก 3.3V กระแสไม่กี่ mA เท่านั้น — ปุ่มที่ระบุสเปคมาตรฐาน 12V DC 1A (ปุ่มกันน้ำทั่วไปแทบทุกรุ่นเป็นแบบนี้) เกินพอสบาย ๆ |
| จำนวนขา | **2 ขา** (สวิตช์อย่างเดียว) หรือ **5 ขา** (สวิตช์ 2 ขา + ไฟ LED ในตัว 2-3 ขา) |
| ไฟ LED ในตัว (ถ้าเลือกรุ่นมีไฟ) | ระบุแรงดัน LED ให้ตรงกับที่จะจ่าย — เลือกรุ่น **3V หรือ 5V** (ต่อตรงจาก ESP32/adapter ได้เลยไม่ต้องมีตัวต้านทานเพิ่ม) หลีกเลี่ยงรุ่น 12V/24V เพราะต้องมีวงจรแปลงไฟเพิ่ม |
| วัสดุตัวปุ่ม | สแตนเลส (metal) ทนแดดฝนกว่าพลาสติกถ้าติดตั้งกลางแจ้งระยะยาว |
| สีแนะนำ | แดง หรือ ส้ม (สื่อถึง "กด/บันทึก" ชัดเจน สอดคล้องกับสีปุ่ม CAPTURE บนหน้าเว็บ) |
| คำค้นหาซื้อ | `ปุ่มกดกันน้ำ 12mm IP65 มีไฟ 5V` หรือ `waterproof momentary push button 12mm LED NO` |
| ราคาโดยประมาณ | ปุ่มธรรมดาไม่มีไฟ 10-20 บาท / ปุ่มกันน้ำมีไฟ 50-150 บาท |

## 3. สายไฟ

| ใช้งาน | สเปค |
|---|---|
| ทดสอบบนโต๊ะ/breadboard | สาย Dupont **Female-to-Female** ยาว 20cm อย่างน้อย 2 เส้น |
| ติดตั้งจริง (ปุ่ม ↔ กล่อง ESP32) | สายทองแดงหุ้มฉนวนกันน้ำ (หรือสายลำโพง 2-core ก็ใช้ได้) ขนาด **22-24 AWG (0.3-0.5 mm²)** อย่างน้อย 2 เส้น (4 เส้นถ้าปุ่มมีไฟ LED ด้วย) ความยาวตามระยะจริงจากจุดติดปุ่มถึงกล่อง |
| หัวต่อ (ถ้าไม่บัดกรี) | เทอร์มินอลบล็อก (terminal block/screw connector) ขนาดเล็ก ใส่ในกล่องกันน้ำ ต่อสายเข้า-ออกโดยไม่ต้องบัดกรี ถอดเปลี่ยนอุปกรณ์ทีหลังง่ายกว่า |

## 4. แหล่งจ่ายไฟ

| หัวข้อ | สเปค |
|---|---|
| Adapter | USB 5V / **1A ขึ้นไป** (หัวชาร์จมือถือทั่วไปใช้ได้เลย ไม่ต้องซื้อพิเศษ) |
| สาย USB | ต้องเป็นสาย **"data" ไม่ใช่สายชาร์จอย่างเดียว** (เผื่อไว้เสียบคอมโปรแกรม/แก้โค้ดซ้ำได้โดยไม่ต้องถอดบอร์ดออกจากกล่อง) — หัวต่อ **Micro-USB** (มาตรฐานของ DevKit ส่วนใหญ่ เช็คให้ตรงกับบอร์ดที่ซื้อ) |
| ความยาวสาย USB | เผื่อระยะจากปลั๊กไฟที่ใกล้ที่สุดถึงจุดติดตั้งกล่อง ถ้าไกลเกิน 3-5 เมตร ควรใช้สาย USB active repeater หรือย้ายมาใช้ adapter ไฟ 5V ต่อสายไฟยาวแทน (ไม่ควรลากสาย USB ธรรมดายาวเกินไปเพราะไฟตกได้) |

## 5. กล่องกันน้ำ (Enclosure)

| หัวข้อ | สเปค |
|---|---|
| เกรดกันน้ำ | IP65 ขึ้นไป |
| ขนาดภายในแนะนำ | อย่างน้อย **100 x 68 x 50 มม.** (พอใส่บอร์ด ESP32 + เทอร์มินอลบล็อก + เดินสาย) |
| วัสดุ | พลาสติก ABS หรือ PC (กันแดด UV ได้ดีกว่า ABS ธรรมดาถ้าโดนแดดจัดต่อเนื่อง) |
| ช่องร้อยสาย | ควรมี **cable gland (พุกยางกันน้ำ)** อย่างน้อย 2 จุด — 1 สำหรับสายไฟเข้า (USB/adapter), 1 สำหรับสายไปปุ่ม |
| คำค้นหาซื้อ | `กล่องกันน้ำ IP65 100x68x50` หรือ `waterproof junction box IP65 with cable gland` |
| ราคาโดยประมาณ | 50-100 บาท |

## สรุปรายการซื้อ (1 คอร์ท)

1. ESP32-WROOM-32 DevKit V1 (CP2102) — 1 ตัว
2. ปุ่มกดกันน้ำ 12mm IP65 มีไฟ 5V (NO) — 1 ตัว
3. สาย Dupont Female-to-Female — 1 ชุด (ทดสอบ)
4. สายไฟกันน้ำ 22-24 AWG — ตามระยะจริง
5. เทอร์มินอลบล็อกขนาดเล็ก — 1 ตัว
6. Adapter USB 5V/1A + สาย USB (data) Micro-USB — 1 ชุด
7. กล่องกันน้ำ IP65 ~100x68x50mm พร้อม cable gland — 1 ใบ

รวมประมาณ **250-450 บาทต่อคอร์ท** (ตามที่สรุปไว้ใน `WIRING.th.md`)
