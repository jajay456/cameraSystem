# ปุ่มกดที่คอร์ทจริง (ESP32) — ของที่ต้องซื้อ + วิธีต่อสาย

คู่มือนี้ครอบคลุมแค่ **ฮาร์ดแวร์**: ซื้ออะไร ต่อสายยังไง ให้ปุ่มกดพร้อมส่ง
สัญญาณ ส่วนโค้ดที่ทำให้ ESP32 ยิง HTTP ไปหาเครื่อง server (`/api/trigger`)
จะทำเป็นขั้นต่อไปหลังต่อสายเสร็จและทดสอบว่าปุ่มกดติดจริง

---

## 1. ของที่ต้องซื้อ

*(สเปคละเอียดของแต่ละชิ้น — รุ่นไหน ขนาดไหน กันน้ำระดับไหน — ดูที่
[SPEC.th.md](SPEC.th.md))*

| อุปกรณ์ | คำแนะนำ | ประมาณราคา |
|---|---|---|
| **บอร์ด ESP32** | ESP32-WROOM-32 DevKit V1 (มีขาย 30 ขา หรือ 38 ขา ก็ได้ — รุ่นไหนก็ใช้ได้ ขอให้เป็น "DevKit" ที่มีพอร์ต USB สำหรับโปรแกรมได้เลย) | ~120-200 บาท |
| **สายโปรแกรม** | สาย USB ต่อบอร์ด (เช็คว่าบอร์ดใช้ Micro-USB หรือ USB-C ก่อนซื้อ ส่วนใหญ่เป็น Micro-USB) | มีติดมากับบอร์ดบางร้าน |
| **ปุ่มกด** | ถ้าจะทดสอบบนโต๊ะก่อน: ปุ่มกด momentary (4 ขา, กดแล้วปล่อยคืนเอง) แบบใช้กับ breadboard ได้เลย ถ้าจะติดตั้งจริงที่คอร์ท (โดนแดด/ฝน/มือกดบ่อย): เลือก **ปุ่มกดกันน้ำ (waterproof push button, IP65 ขึ้นไป)** แบบติดหน้ากล่อง มักเป็นทรงกลมมีไฟ LED ในตัว | ปุ่มธรรมดา ~10-20 บาท / ปุ่มกันน้ำมีไฟ ~50-150 บาท |
| **สายไฟ/สาย Dupont** | แบบ Male-to-Female หรือ Female-to-Female อย่างละ 1 ชุด (ใช้ต่อขาปุ่มเข้าขา ESP32) | ~30-50 บาท/ชุด |
| **Breadboard** (ทางเลือก) | ใช้ตอนทดสอบบนโต๊ะก่อนติดตั้งจริง ไม่บังคับถ้าจะบัดกรีสายตรงเลย | ~30-50 บาท |
| **แหล่งจ่ายไฟ** | Adapter USB 5V (เช่นหัวชาร์จมือถือทั่วไป) + สาย USB ยาวพอไปถึงจุดติดตั้ง | มีอยู่แล้วส่วนใหญ่ |
| **กล่องกันน้ำ** (ถ้าติดตั้งกลางแจ้ง) | กล่องพลาสติกกันน้ำใส่บอร์ด ESP32 เจาะรูเดินสายไฟออกไปหาปุ่ม | ~50-100 บาท |

**สรุปงบประมาณต่อ 1 คอร์ท**: ประมาณ 250-450 บาท (ถ้าใช้ปุ่มกันน้ำมีไฟ)

ซื้อได้จากร้านอุปกรณ์อิเล็กทรอนิกส์ทั่วไป (เช่น Chip1Stop, Arduino Thailand,
IC Station) หรือสั่งออนไลน์ (Shopee/Lazada ค้นหา "ESP32 DevKit" กับ
"waterproof push button 12mm")

## 2. แผนภาพต่อสาย

ปุ่มกด momentary มี 2 ขาใช้งาน (หรือ 4 ขา แต่ทำงานเป็นคู่ ๆ ละ 2 ขาเชื่อม
กันตลอด) — ต่อง่าย ๆ แค่ 2 เส้น ไม่ต้องมีตัวต้านทานเพิ่ม เพราะ ESP32 มี
**internal pull-up resistor** ในตัว เปิดใช้ผ่านโค้ดได้เลย

```
        ESP32 DevKit
        ┌───────────────┐
        │               │
        │         GPIO4 ●──────────┐
        │               │          │
        │           GND ●───────┐  │
        │               │       │  │
        └───────────────┘       │  │
                                 │  │
                            ┌────┴──┴────┐
                            │   ปุ่มกด    │
                            │  (button)   │
                            └─────────────┘
```

- ขาปุ่มข้างหนึ่ง → **GND** ของ ESP32
- ขาปุ่มอีกข้างหนึ่ง → **GPIO4** (หรือขาอื่นตามตารางด้านล่าง)
- เวลากดปุ่ม วงจรจะครบ (GPIO4 ต่อถึง GND) → ค่าที่อ่านได้จาก GPIO4 จะ
  เปลี่ยนจาก HIGH (ปกติ ปุ่มไม่ได้กด) เป็น LOW (ตอนกด) — โค้ดฝั่ง ESP32
  จะเช็คตรงนี้แล้วยิงสัญญาณไปเครื่อง server

ถ้าปุ่มที่ซื้อมามีไฟ LED ในตัวด้วย (ปุ่มกันน้ำหลายรุ่นมี) จะมีสาย
เพิ่มอีก 2 เส้นสำหรับไฟ LED (ต่อผ่าน GPIO อีกขา + GND หรือ 3.3V ตามที่
ปุ่มรุ่นนั้นกำหนด — ไฟ LED นี้ใช้ทำตอบสนองตอนกด/ตอนกำลังตัดคลิปได้ทีหลัง)

## 3. เลือกขา GPIO ไหนดี

**แนะนำใช้ได้เลย**: GPIO 4, 5, 13, 14, 16, 17, 18, 19, 21, 22, 23, 25, 26,
27, 32, 33

**ห้ามใช้กับปุ่ม** (เป็นขาที่ ESP32 ใช้ตอนบูตเครื่อง ถ้ามีอะไรต่ออยู่ตอน
เปิดเครื่องอาจบูตไม่ขึ้นหรือมีพฤติกรรมแปลก ๆ): GPIO 0, 2, 12, 15
(และ GPIO 6-11 ใช้ต่อกับ flash memory ในตัวบอร์ดอยู่แล้ว ห้ามยุ่งเด็ดขาด)

ในคู่มือนี้ใช้ **GPIO4** เป็นตัวอย่าง จำเลขขาที่เลือกไว้ให้ดี เพราะตอน
เขียนโค้ดฝั่ง ESP32 (ขั้นต่อไป) ต้องใส่เลขขานี้ในโค้ดให้ตรงกับที่ต่อจริง

---

## 4. ทดสอบก่อนเขียนโค้ด (แนะนำ)

ก่อนเดินสายจริงไปติดที่คอร์ท ให้ต่อบนโต๊ะ/breadboard ก่อน:
1. เสียบ ESP32 เข้าคอมด้วยสาย USB
2. ต่อปุ่มตามแผนภาพด้านบน (GPIO4 ↔ GND)
3. รอโค้ดทดสอบขั้นต่อไป (จะเขียนให้กดปุ่มแล้วเห็นข้อความบนคอมทันที) เพื่อ
   ยืนยันว่าปุ่มกดติดจริงก่อนเดินสายจริง
